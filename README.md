# wardogs

Fan-made tools for playing WARDOGS with friends. Live at https://jtac.github.io/wardogs/

- `countdown/` — Deployment Clock: countdown to the Steam Early Access unlock (10 Sep 2026, 16:00 UTC)
- `assets/brand/` — brand notes and CSS tokens derived from the Team17 press kit (art files not committed)
